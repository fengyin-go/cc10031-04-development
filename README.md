# RPA流程自动化中心

面向企业数据采集场景，提供RPA流程编排、元素定位、执行调度和结果校验的自动化运营平台

这是一个前后端分离的管理平台：前端 Vue 3 + Vite + TypeScript，后端 FastAPI（Python）。
两边各自独立启动，前端 dev server 已关掉自动打开页面，启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端
│   ├── src/views/WorkbenchView.vue|tsx  全部模块共享工作台
│   ├── src/data/modules.ts              18个业务模块配置
│   ├── src/api/              统一请求封装
│   └── vite.config.ts        dev server 配置（open: false）
├── backend/                  FastAPI（Python） 后端
│   ├── app/routers/resource.py  通用查询/导出/登记/动作接口
│   ├── app/services/<key>.py    每个模块独立领域逻辑
│   ├── app/services/base.py     共享服务骨架
│   └── app/store.py          内存数据仓库与示例数据
├── .gitignore
└── docker-compose.yml
```

## 启动

### 后端

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run.sh
```

健康检查：`curl http://127.0.0.1:8000/api/health`

### 前端

```bash
cd frontend
npm ci
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，
需要自己访问。`/api` 由 vite 代理到后端 `http://127.0.0.1:8000`。

## 约定

- 全部模块共享`frontend/src/views/WorkbenchView.vue|tsx`和一套资源路由。
- 每个模块仍保留独立`backend/app/services/<模块>.py`；纯前端保留
  `frontend/src/domain/<模块>.ts`，用于承载真实业务差异并维持36题位容量。
- 列表接口统一返回 `{ items, total, page, size }`，动作接口统一返回 `{ ok, message }`。
- 状态流转只允许在 `app/services` 里改，路由层不做业务判断。

## 批次完整性对账

批次追踪的目标数 / 成功数 / 隔离数分别存放在采集批次、采集记录与隔离记录三个对象中。
`backend/app/services/batch_integrity.py` 把它们按批次还原成一张对账表：

- 勾稽公式：`目标条数 = 成功条数 + 隔离条数 + 采集缺口`
- 每条遗漏项带 `owner_flow`（责任流程）与 `source_batch`（来源批次），可逐项追溯
- 已被「新到达批次」恢复的隔离项不再计入待补采遗漏
- 采集记录与隔离记录按 `record_key` 去重，重复导入只认第一条

归属与补采规则：

- 同一批次同时有流程内遗漏和外部隔离时，可「按流程拆分」或「整批冻结统一认领」
- 两种路径都只允许一个最终责任人；第二个责任人会产生归属冲突，批次进入
  第 4 阶段处理终态（归属冲突待裁决），由平台管理员裁决后才可继续
- 补采任务清单（处理项丁）按批次完整性报告版本生成，只为本流程缺失项写入
  责任人和补采范围，并联动写入任务队列待办
- 权限为受控只读：`viewer` 只能查看报告与当前责任人，`flow_owner` 只能操作
  本流程，`admin` 可代为裁决归属冲突

页面入口：批次追踪工作台的「批次完整性报告」按钮，路由 `/batch_tracker/integrity`。
接口前缀 `/api/batch-integrity`：`/reports`、`/reports/{批次编号}`、
`/reports/{批次编号}/ownership`、`/ownership/resolve`、`/resupply`、`/trace/{记录键}`、`/snapshot`。
